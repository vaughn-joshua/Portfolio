# My Portfolio

This is my portfolio website showcasing my projects, skills, and experience.

## Versions

This repo keeps past versions of the portfolio so they can always be revisited.

- **`v1`** (tag) — the pre-internship portfolio (built Jan 2026). This is the
  first version of the site. To view it: `git checkout v1`
- **`before-internship`** (branch) — a branch snapshot of the same pre-internship
  version, kept as a backup.
- **`post-graduation`** (branch) — the current redesign, built after the
  Feb–Jun 2026 internship. This is where new work happens.

Tags are frozen and never move, so `v1` will always point at the original
portfolio even as the redesign branches move forward.
